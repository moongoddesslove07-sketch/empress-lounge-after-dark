# Empress Lounge — Freaky Friday After Dark

A single-file, full-screen interactive prototype designed for use alongside TikTok LIVE Studio.

## Included
- Animated CSS futuristic city with moving light trails, animated skyline, road lights and water shimmer.
- Six floating scenario cards.
- Click-to-open scenario scenes and dialogue.
- Browser speech synthesis for dialogue (voices vary by device/browser; this is not studio-quality recorded acting).
- Audience-question reveal, host tally controls, and keyboard shortcuts 1–6.
- Responsive layout and reduced-motion accessibility support.

## Preview locally
Open `index.html` in a modern browser. Internet connection is not required for the visual effects; voice availability depends on the browser/device.

## Publish with GitHub Pages
1. Create a new public repository named `empress-lounge-after-dark`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. When deployment completes, open the URL shown on the Pages settings screen.

GitHub Pages sites are public. Do not place private information in the repository.

## Important limitations
This is the first interactive prototype. The character art is stylized CSS artwork, not photorealistic generated actors. Speech uses built-in browser text-to-speech; voice quality and available voices vary. Live audience comments are not automatically connected to the app; the host can count comments and use the tally buttons.
